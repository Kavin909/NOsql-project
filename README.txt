SMART CITY DATA HUB - 3D live dashboard

OPTION A (no install): double-click index.html (keep sim.js in same folder). Needs internet for three.js.
OPTION B (saves JSON file):
  1. Install Node.js LTS from nodejs.org
  2. In this folder run:  node server.js
  3. Open http://localhost:3000
  Sensor data saved every 2 sec in sensor_data.json
